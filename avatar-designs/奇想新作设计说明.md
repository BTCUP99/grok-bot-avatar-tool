# 奇想新作 · 20 款原创动态角色

工具 1.2.0 新增 12–31 号，与原有十一款共存。设计源为 fantasy-shapes.js；catalog-shapes.js 提供共用实体注册与曲面装饰工具。

## 造型方向

这批覆盖天空与海洋生物、怪趣食物、纸艺与软雕塑、森林精灵和抽象物件。每款拥有独立轮廓、厚度、倒角、眼睛比例、配色与曲面装饰；灯位融入雨滴、星斑、裂纹、骰点或花苞。

立体感来自原生实体轮廓投影、厚度、倒角与随姿态变化的曲面贴附。渐变和色块表达玻璃、绒面、瓷釉、折纸等视觉风格，不宣称物理材质模拟。彩结的交叠与奶酪孔洞是曲面色彩错觉，仍使用单一实体模型。

## 角色性格

- **云朵鲸**：一朵忘记下雨的云，长出了鲸鱼尾巴。把忙碌藏在额头的小雨滴里。
- **熔岩吐司**：看起来刚刚烤焦，其实正在用地心热量替你处理工作。笑起来像一块热黄油。
- **布丁幽灵**：不吓人，只会偷偷把你的待办吃掉。它的裙边是一圈晃来晃去的布丁褶。
- **折纸狐狸**：一张不肯安静躺着的珊瑚色纸。转头时折面和厚度一起显露，像被风吹活了。
- **苔岛山灵**：一座长着眼睛的迷你浮岛。头顶四季积雪，脸颊有两道刚刚醒来的溪流。
- **绒球刺猬**：一团有边界感的毛球。刺是软的，眼神却认真得像一位微型管理员。
- **泡泡章鱼**：八只手忙着捉灵感，表情却永远从容。每颗吸盘都是一颗海底珍珠。
- **宇宙蜗牛**：背着一整圈银河，慢慢把复杂问题搬回家。宇宙很大，它很稳。
- **唱片黑洞**：一颗喜欢听老唱片的黑洞。吸进去的是噪声，吐出来的是好主意。
- **弹簧果冻**：把三层果冻叠成了一个小宇宙。身体可以扭，工作态度不能塌。
- **悬浮骰子**：把运气装进一颗有厚度的奶白骰子。它认真思考，不会替你胡乱掷答案。
- **灯笼河豚**：一紧张就把自己点亮的河豚。每根刺都圆钝，像一盏暖黄的小夜灯。
- **星轨水滴**：从一条星轨上掉下来的玻璃水滴。额头那点光，是它尚未用完的宇宙电量。
- **吐舌涂鸦**：一滴不肯按形状待着的油漆。它的灵感会溅出来，完成事情还要调皮一下。
- **奶酪月球**：月球真的是奶酪做的吗？它不回答，只把自己的小坑洞擦得亮亮的。
- **绯红折翼**：像一枚会思考的蝴蝶结，也像两片折起的彩色玻璃。每次回头都换一组折面。
- **翡翠仙人掌**：一株把刺磨成玉点的仙人掌。举着双手，像随时准备说“这件事交给我”。
- **蘑菇占卜师**：总是把帽檐压得很低的小蘑菇。帽上的星斑会告诉你，它还在努力思考。
- **天鹅绒蝠**：看上去很酷，其实怕你熬夜。两只宽翼像一条能把烦恼裹起来的小披风。
- **彩虹拓扑**：一个试图把自己解开的彩色结。看起来有点不可能，却每次都能稳稳回到原位。

## 共用规格

- 单一实体轮廓与原生曲面座；眼睛沿用原生表情轮廓、眨眼和遮挡。
- 实际显示 36 × 36 / 64 × 64 CSS px；共享源分辨率 192。交付 1024 × 1024 透明 PNG 与可缩放 SVG。
- 六基准姿态及四个斜向，共十方向；输出尺寸 36、64、192、1024 均检查裁切与有限坐标。
- 53 种原生状态均抽样检查；特殊形变继续交给原生引擎。
- 工作灯周期 1.3 秒，完成使用原生 happy + 一次 nod，不增加独立常驻动画循环。
- 每款包含独立 JSON、四状态 SVG/PNG、四状态规格图，以及六姿态参数快照和 SVG。

完整精确数值以 runtime-bean/library/characters/ 和 specs/ 为准。离线素材不能替代实际窗口的原生悬停与回位验收；验证范围见 runtime-bean/头像库使用说明.md。
