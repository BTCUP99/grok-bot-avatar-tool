# 霓虹夜行：原生交互、工作状态灯与完成响应

适配范围：2026-11-04，官方 Grok Bot 0.78.4 / macOS Apple Silicon。只覆盖本地配置的测试 Bot；官方安装包、签名、服务器头像和其他 Bot 不做修改。

## 使用

先用 Command-Q 退出 Grok Bot，再使用统一入口：

- [启动头像工具.command](../启动头像工具.command)：在“对话详情 → 点击头像 → 原创动态头像”选择霓虹夜行，跟随实际任务状态。
- 开发者可执行 `node runtime-bean/tool.mjs --demo`：额外显示明确标记的工作与完成外观演示；不发送消息、不运行 Bot 任务。

演示面板的“演示工作状态”让头像进入工作反馈；“演示完成响应”显示开心并点头一次，约 4.2 秒后恢复跟随实际状态；“跟随实际状态”可立即结束演示。真实任务模式没有这段演示计时器。

恢复服务器原头像：Command-Q 完全退出，再从 Applications 或原 Dock 图标正常打开。公开包只保留一个日常启动入口。

## 外观与参数

霓虹夜行注册键为 `neonNight`。它复用奶糖喵机经过验收的几何、原生眼睛轮廓和曲面装饰布局，再增加独立材质和状态灯；没有改写 `bean-shape.js` 或 `milkcat-shape.js`。

| 项目 | 参数 |
| --- | --- |
| 几何 | 原生 extrusion；比例 1.22、半深度 .29、倒角 .14、轮廓采样步长 2 |
| 眼睛布局 | 宽 .24、高 .41、间距 .49、偏移 .08；沿用奶糖的原生表情纵横比适配 |
| 外壳渐变 | `#7379bd` → `#303953` → `#0d1626` |
| 面甲 | 外层 `#64dbea`，内层 `#111b33` |
| 眼睛 | `#91f9fa`；原生眼形、眨眼和眼睑裁切 |
| 腮红 / 耳内 | `#bb85ff` / `#9b9be7` |
| 边缘亮线 | `#b2ceff`，宽度为内部坐标尺寸的 .009，透明度 .5 |
| 玻璃反光 | 通过原生曲面投影的亮条与斜向淡光，不是独立平面贴图 |
| 眼灯光晕 | `#5df8ff`，透明度 .38；按已投影眼睛轮廓生成，显示尺寸至少 48 时启用模糊 |
| 闲置 / 工作 / 完成灯色 | `#8ef9e8` / `#5df8ff` / `#c9ff83` |
| 等待 / 受阻或失败灯色 | `#bf9bff` / `#ffca7d` |
| 工作灯亮度 | 原生引擎推进的渲染时钟驱动，周期 1.3 秒，范围 .55–1；没有常驻独立刷新计时器 |
| 工作灯位置 | 额头与耳部，通过同一原生曲面座随身体姿态投影 |

额头灯、耳灯和眼内高光受身体轮廓裁切。SVG ID 使用每次渲染传入的唯一 ID，防止多个头像串用遮罩。共享源分辨率、36 / 64 CSS 像素容器、原生 `fill` / `zoom`、姿态平滑和指针事件均沿用现有实现。

## 状态与动作

`neon-bridge.js` 观察客户端已有的目标 Bot 状态源，将同一份状态提供给共享侧边栏角色与独立详情角色。它只接收状态和完成时间标识，不读取聊天正文或发起任务。

工作、思考、搜索、阅读、编码、执行、发送等状态启用青蓝工作反馈。原生思考 / 等待 / 上传等形变继续使用原生通用渲染，统一霓虹配色并保留状态灯，不屏蔽形变。

客户端报告 `finished` 时，使用原生 `setExpression('happy')` 和 `poke('nod')`。以真实完成时间标识去重，每个可见原生引擎对同一次完成只执行一次点头；重复渲染不会再次触发。失败和取消不触发成功庆祝。原生完成状态、工作动作、眨眼和回位仍由原引擎负责。

霓虹角色只增加一个随原生 `advance` 推进的材质时钟，并记录原生点头调用用于验收；没有重新实现姿态或伪造鼠标事件。组件原有的可见性、静止停止刷新与减少动态效果机制保留。

## 验收与证据

真实窗口证据保存在本机 `evidence/neon-night/`，不进入公开包：

- 侧边栏 36 × 36 与详情 64 × 64，各两轮真实鼠标悬停中心、保持正脸、移开回位。记录 `trusted: true`、`buttons: 0`，正面 / 回位四元数与原生基准一致。
- 工作灯在真实窗口的本机演示模式下变化，侧边栏与详情同步进入工作状态。
- 两次完成演示均出现原生开心表情和点头；相邻帧中的姿态发生变化，点头计数只增加一次；演示结束后恢复真实闲置状态及原生回位姿态。
- 普通重启恢复服务器原头像、关闭调试端口；专用启动器重启重新生效。
- 官方代码签名、ASAR 哈希及本机所有 Bot 的持久化头像字段与验收前对比。

**工作与完成的本轮窗口验收使用明确标记的本机外观演示。没有发送测试消息或运行真实 Bot 任务，因此不能把演示记录写成一次真实任务完成的证据。** 实际任务的状态观察与演示共用头像状态订阅和原生动作路径。

验收观察器会在 SVG 被原生渲染器替换后重新定位当前节点，并读取真实 `pointerup`，避免将旧 SVG 或按下时的最后一次 `pointermove` 当成释放后的状态。

## 文件与复现

- `neon-shape.js`：材质、曲面状态灯、形变配色与目标角色渲染时钟。
- `neon-state.mjs`：纯本地状态存储、演示覆盖、过期保护和完成去重。
- `neon-bridge.js`：哈希限定的 React 状态接入和可选演示面板。
- `verify-neon.mjs`：原生 25 形状的 75 组回归、霓虹转向 / 眨眼、53 状态共 159 个抽样渲染、工作灯变化、开心与点头和完成去重检查。
- `霓虹夜行参数快照.json`、`霓虹夜行规格图.svg`：由原生引擎重建的离线参数与六姿态规格图。

```bash
node runtime-bean/spec.mjs
node runtime-bean/spec.mjs --shape milkcat
node runtime-bean/spec.mjs --shape neonNight
node runtime-bean/verify.mjs
node runtime-bean/verify-neon.mjs
```

开发验收启动：`node runtime-bean/start.mjs --shape neonNight --audit --demo`。`--demo` 只用于霓虹角色，未给该参数时不创建演示面板。官方版本、架构、签名和厂商输入哈希的限制保持有效。
