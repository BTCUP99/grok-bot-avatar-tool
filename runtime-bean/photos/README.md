# 虚拟人物头像素材

本目录的 11 张图片均由项目维护者自行生成，是虚拟人物图像，并非真人摄影作品。维护者已确认将这些原创示例随本项目公开发布，适用根目录的 [MIT 许可](../../LICENSE)。它们不是 Grok Bot 官方素材，也不表示图中虚拟人物与任何真实个人存在关联。

图片经过逐张近景裁切与等比例缩放，运行时统一使用 256 × 256 PNG。近景版直接从提供的原图像素裁出，裁片边长为 395～735 像素；`framing.json` 保存裁切坐标和图像哈希，不包含本机路径或个人身份信息。

名称、编号、运行时键和固定 SHA-256 见上级 `avatar-catalog.mjs`。`photo-runtime.js` 只让整张图片倾斜、转正、回位、亮柔光或轻弹，素材不包含额外眨眼、嘴型或面部重绘。

“写真头像”是工具界面中的风格分类标签，不代表这些示例是真人写真。状态演示与隔离验证不等同于真实 Bot 任务端到端验收；当前验证范围见项目 README。
