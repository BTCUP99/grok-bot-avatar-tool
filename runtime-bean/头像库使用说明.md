## 打开与切换

统一日常入口是根目录 `启动头像工具.command`。完整用户包自带官方 Node.js 运行环境。

已有用户升级：退出 Grok Bot 后，将新版文件更新到原工具目录，保留 `runtime-bean/config.local.json`。若解压到新目录，将旧目录的这个配置文件复制过去，便可沿用选择；配置只用于自己迁移，不要放进分享包。

首次先登录官方 Grok Bot、同步侧边栏并 Command-Q 退出；双击统一入口即可启动，无需事先选择 Bot；在任意 Bot 的头像窗口里选择款式。以后双击同一个入口即可。

头像窗口有“原创动态头像 / 写真头像 / 官方选项”三个标签。动态角色和写真都支持按名称、英文键或编号搜索；动态角色还能按“全部 / 奇想新作 20 / 初代 11”筛选。卡片区独立滚动，应用按钮保持可见。

选择入口是 **对话详情 → 点击头像 → 原创动态头像 / 写真头像**。卡片先暂存选择，点“应用头像”后才同步更新侧边栏、标题和详情，并保存到 `config.local.json`；点“取消”不会修改选择。重开头像窗口会标记已应用的款式。

普通模式没有额外的右下角切换面板。开发者可用 `node runtime-bean/tool.mjs --demo` 打开明确标记的工作/完成外观演示，用 `--audit` 查看原生指针与姿态。

“官方选项”保留原生上传、生成和默认形状设置；其原始数据和云端行为不被本机选择冒充。动态角色和写真覆盖仅在此设备、你选过款式的 Bot 上生效，每个 Bot 独立；“恢复原头像”只清除当前 Bot 的本机选择。普通官方入口重开不加载本工具，但不会删除素材或本机选择。

普通用户无需输入 Bot 名称或 ID。`npm run configure` 可重新打开启动设置页面；更换某个 Bot 的头像直接在它自己的头像窗口完成。

## 原生动态角色响应

- 真实鼠标悬停中心转正，移开恢复原生闲置侧脸；保留原生视线、姿态平滑、眨眼和九种表情。
- 工作、思考、搜索、编码、运行等状态启用青蓝工作反馈，灯光周期 1.3 秒。灯位贴附原生曲面，随实体转向；显示尺寸小于 48 时不增加模糊光晕。
- 特殊形变继续使用原渲染器，保留状态语义，统一角色配色和状态灯。
- 客户端报告 `finished` 时调用原生 `setExpression('happy')` 与 `poke('nod')`。每个引擎对每个完成标识只点头一次；失败和取消不触发成功庆祝。
- 状态来源是客户端已有的各 Bot 活动状态与完成时间标识（每个 Bot 独立），不读取对话正文或发起任务。材质时钟跟随原生 `advance`，没有常驻独立动画计时器。

演示只覆盖本机头像状态。完成演示约 4.2 秒后恢复真实状态，也可立即点“跟随实际状态”。切换款式保留正在进行的真实任务状态。真实任务模式没有这段演示计时器。

## 复用与高清素材

`library/` 是交付资产目录：

- `manifest.json`：31 款参数、灯光、完成响应和源码/官方输入哈希。
- `characters/`：每款独立 JSON，包含原创轮廓、装饰曲线、眼睛布局、材质和响应参数。
- `icons/`：每款闲置、正面、工作、完成四状态，**1024 × 1024 透明 PNG + 可缩放 SVG**，共 124 对。实际交互由程序化几何驱动。
- `sheets/`：每款四状态规格图，SVG + PNG。
- `specs/`：30 款六姿态参数与 SVG；霓虹基准仍在上一级 `霓虹夜行参数快照.json` / `霓虹夜行规格图.svg`。
- `index.html` / `机器人头像库总览.png` / `奇想新作总览.png`：可直接打开的离线画廊与总览，不依赖 HTTP 服务。

`photos/` 另存 11 张运行时写真 PNG，`avatar-catalog.mjs` 记录其名称、编号、尺寸校验与内容哈希；照片不需要四种表情图，也不进入原生角色的 124 对状态素材。这些示例均为维护者自行生成的虚拟人物图像，随项目按 MIT 许可公开，来源见 [素材说明](photos/README.md)。

其他项目可复用原创轮廓、装饰和材质参数。原生投影和动作依赖 Grok Bot 的版本限定引擎，单个 PNG 或 JSON 本身不会产生原生交互。在另一台符合条件的 Mac 使用时，解压完整复用包，再从启动器打开，在各 Bot 的头像窗口选择。

## 源码职责

- `../avatar-designs/catalog-shapes.js`：原十款原创几何、眼睛与装饰的单一来源；旧候选画廊保留原交付。
- `../avatar-designs/fantasy-shapes.js`：新增二十款几何、色彩与装饰；设计说明见同目录 `奇想新作设计说明.md`。
- `library.mjs`：31 款原生角色清单、运行时键、灯形、灯位和闲置灯色。
- `avatar-catalog.mjs`：全部 42 款可选清单及写真图片校验。
- `photo-runtime.js`：写真组件、共享指针、轻倾斜、工作柔光与完成去重。
- `library-runtime.js`：全部 catalog 角色的状态灯和原生材质；霓虹沿用 `neon-shape.js`。
- `library-state.mjs`：可订阅的款式选择、实际状态和演示覆盖，复用 `neon-state.mjs` 的完成去重。
- `library-bridge.js`：可见头像的状态订阅和原生引擎引用。
- `library-picker.js`：每个 Bot 的原生头像编辑入口、动态/写真/官方标签、42 款卡片、搜索与分组、取消/应用与恢复。
- `tool.mjs` / `setup-server.mjs`：统一启动与网页式首次配置。
- `patch.mjs` / `loader.mjs`：按本机分配表的内存适配，仅把合法的 (Bot ID, 款式) 选择保存到本机配置。

不用为每款复制状态或鼠标逻辑。颜色和灯位在 `library.mjs`；原十款轮廓和面甲在 `catalog-shapes.js`；霓虹材质在 `neon-shape.js`。动态角色切换时用 React key 重建该款原生角色，原鼠标回调继续负责 gaze；写真由独立组件接收相同的指针语义。两个类型共用每 Bot 选择和活动来源，各自保留独立渲染方式。

旧 `--shape milkcat` 和 `--shape apricotBean` 仅保留作开发回归入口。公开包只提供 `启动头像工具.command`；日常奶糖请选择库中的 `robot_milkcat`。
