# 奶糖喵机 · 第 1 款运行时接入

2026-11-04，macOS Apple Silicon / 官方 Grok Bot 0.78.4。沿用已配置的测试 Bot，不上传云端头像，不发送消息，也不修改其他 Bot。

## 使用与恢复

1. 若客户端正在运行，先 Command-Q 正常退出。
2. 双击项目根目录的 [启动头像工具.command](../启动头像工具.command)，在“对话详情 → 点击头像 → 原创动态头像”选择奶糖喵机并应用。
3. 在测试 Bot 侧边栏头像和详情头像的中心停留，奶糖喵机会转正并保持；移到旁边空白处后恢复倾斜闲置姿态。
4. 恢复服务器原头像：Command-Q 退出，再从 Applications 或原 Dock 图标正常打开。

详情头像悬停时会显示客户端原有的变暗遮罩和铅笔图标；没有禁用编辑遮罩，也不需要点击它。

## 形体与外观

源码为 [milkcat-shape.js](milkcat-shape.js)，注册键 `milkcat`。对应十款设计中的 `robot_milkcat`，只更换运行时形状键。离线检查逐一对比十姿态 × 36 / 64 / 192 三尺寸，确认接入造型与选定设计的 SVG 一致。

| 项目 | 参数 |
| --- | --- |
| 原生几何 | `vc(1.22, Cc(z('milkcat', 2)), .29, .14)`，带厚度与倒角的 extrusion |
| 曲面座 | 原生 `front`，`faceZ = 0.29`；随身体四元数一起投影 |
| 眼睛布局 | `width: .24, height: .41, gap: .49, shiftY: .08` |
| 眼睛纵向比例 | 原生表情轮廓投影前应用 `.41 / (.24 × (.5244 / .2392))`；保留原生眨眼与表情输入 |
| 身体渐变 | 中心 `(0.30r, 0.20r)`，半径 `0.86r`；`0: #fffdf1, .58: #f6dfca, 1: #d7ac9e` |
| 眼睛 | `#fff4db`，实色；高光按每只投影眼睛裁切 |
| 面甲 | 外层 `#8f6267`，内层 `#4b414b` |
| 耳内 | `#eab3b6` |
| 腮红 | 中心 `±.49, -.27`，半径 `.115 × .045`，`#f09ca8`，透明度 `.8` |
| 嘴部装饰 | 中心 `0, -.43`，尺寸 `.10 × .035`，`#e8a9b8` |
| 额头圆点 | 中心 `0, .53`，半径 `.045`，`#c88e83` |

所有装饰通过原生 `tl` 投影，受身体轮廓裁切；眼睛来源于原生表达轮廓 `ko`，不是静态覆盖层。静止缩放仍为 `0.6`，侧边栏容器 36 × 36、详情容器 64 × 64 CSS px。闲置 / 正面四元数和过渡系数沿用 [共用制作规范](头像制作规范.md)。

## 验收记录

已使用本机原生 UI 工具，将真实鼠标从空白处移至头像中心并松开按键。侧边栏与详情各完成两轮中心保持、移开回位。记录均为 `trusted: true`、`buttons: 0`；中心 `gaze = [0,0]`，稳定正面 `1.00000,0.00000,0.00000,0.00000`，移开后恢复 `0.91700,-0.19158,0.24767,0.24713`。详情两次正面记录相隔约 51 秒，中间完成一次移开回位。

正常退出后从官方入口重开，恢复服务器原头像，调试端口关闭；再次运行奶糖专用启动器，奶糖喵机重新生效，普通使用不显示验收面板。官方签名与 ASAR 哈希复核通过；目标 Bot 缓存中的持久化头像字段与验收前一致。

本机证据在 `evidence/milkcat/`，包括真实窗口截图、八次稳定姿态观察、恢复 / 重新启动截图与 `verification.json`。证据与本地 Bot 配置不进入公开包。本机实际窗口效果对照是截图裁切拼版，区别于离线规格图；公开包不包含该私人截图。

重建与回归：

```bash
node runtime-bean/spec.mjs
node runtime-bean/spec.mjs --shape milkcat
node runtime-bean/verify.mjs
```

当前回归包括两种接入方案下原生 25 种形状共 150 组姿态一致性、六次转正回位、两种角色的原生眨眼和奶糖与候选设计的 30 组一致性检查。版本、架构、厂商输入哈希检查保持有效。
